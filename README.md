🧸 Toy Store
A modern, responsive toy store web application built with React, Vite, Tailwind CSS, and Firebase. This project showcases a professional e-commerce homepage featuring dynamic components, user authentication, and engaging UI/UX design.

🔑 Features
- 🎠 Homepage Slider with promotional banners
- 🧩 Popular Toys Section powered by JSON data
- 🎨 Responsive UI with Tailwind CSS and DaisyUI
- 🔐 Firebase Authentication (Sign up, Login, Logout)
- 🧭 Client-side Routing with React Router
- 📊 Dynamic Charts and Icons for visual engagement
- ✅ Form Validation with Regex
- 🌐 Deployment-ready with optimized build

🛠️ Getting Started
Prerequisites
- Node.js (v18+ recommended)
- npm or yarn
Installation
git clone https://github.com/fahim26-maker/toy-store.git
cd toy-store
npm install


Development
npm run dev


Production Build
npm run build


Preview Production Build
npm run preview



🔧 Firebase Setup
- Create a Firebase project at firebase.google.com
- Enable Authentication (Email/Password)
- Add your Firebase config to a .env file:
VITE_API_KEY=your_api_key
VITE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_PROJECT_ID=your_project_id
VITE_STORAGE_BUCKET=your_project.appspot.com
VITE_MESSAGING_SENDER_ID=your_sender_id
VITE_APP_ID=your_app_id
